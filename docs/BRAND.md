# Quanta brand

**Quanta. A space to think.**

Quanta is a whiteboard and notebook for working things out: handwriting, maths,
physics, and runnable code on one shared canvas. Lead with that purpose; explain
hosting, AI providers, and protocols where they help someone use the product.

## Identity

The Q mark pairs a circular thought with a pen-like finishing stroke. Use
`client/favicon.svg` for the app and `site/favicon.svg` for the independently deployed
website. Keep these files identical. Preserve the mark's proportions and leave
at least one quarter of its width clear around it.

The wordmark is **Quanta**, set in Manrope ExtraBold with tight tracking. Use
Manrope for interface and website text, and DM Mono for code and technical labels.
System font fallbacks keep both usable without a font connection.

| Colour | Value | Use |
| --- | --- | --- |
| Ink | `#252824` | Mark background, wordmark, strong text |
| Citron | `#e4ed87` | Mark stroke, primary actions, small highlights |
| Paper | `#f8f9f3` | Quiet background and sidebar |
| Wash | `#f0f3d9` | Selected navigation and soft accents |
| Olive | `#535c24` | Text and icons on light brand surfaces |

Use dark ink on citron; citron is too light for text on white. Keep the canvas
neutral so the user's work takes priority. Blue remains an interaction colour
for focus, selections, and functional controls. Never use brand colours to
replace warning, error, or collaborator colours.

## Voice

Be curious, clear, and practical. Prefer “Sketch, solve, and work things out
together” to feature-heavy slogans. Use “A space to think.” consistently in the
website, sidebar, and welcome screens. Describe local storage precisely; optional
cloud AI and invitations have their own data-sharing behaviour.
