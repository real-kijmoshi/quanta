Get started

Up and running in a minute

Needs Node.js 22 or newer. Downloads are checked against a published SHA-256 before anything is installed.

curl -fsSL https://github.com/real-kijmoshi/quanta/releases/latest/download/install.sh | sh

Installs to ~/.quanta and links quanta into ~/.local/bin. Read the script first: install.sh.

irm https://github.com/real-kijmoshi/quanta/releases/latest/download/install.ps1 | iex

Run in PowerShell. Installs to %USERPROFILE%\.quanta and adds quanta to your PATH. Read the script first: install.ps1.

docker run -d --name quanta -p 127.0.0.1:4173:4173 -v quanta-data:/data \ -e QUANTA_AUTH=1 -e QUANTA_PUBLIC_URL=http://localhost:4173 \ -e QUANTA_ADMIN_EMAIL=you@example.com -e QUANTA_ADMIN_PASSWORD=choose-a-long-password \ ghcr.io/real-kijmoshi/quanta:latest

Containers run in account mode: open http://localhost:4173 and sign in with that email and password. For an HTTPS team server on a real domain, see Run it for a team below.

npm install -g https://github.com/real-kijmoshi/quanta/releases/latest/download/quanta.tgz
git clone https://github.com/real-kijmoshi/quanta.git cd quanta npm ci --ignore-scripts npm start

Then run quanta start --open. Updating is re-running the installer; your boards are never touched.

Command line

The quanta command

One entry point for running, sharing and looking after your workspace.

quanta start --openRun locally and open your browser
quanta shareLet other devices on your network join (needs a folder invitation)
quanta tunnelShare over the internet with a Cloudflare quick tunnel
quanta backupSave a verified copy of your boards
quanta doctorCheck Node.js, data folder and optional tools
quanta --port 8080 --data ~/boardsChoose the port and where boards are stored

Your boards are plain JSON in ~/.quanta/data, so updating never touches them.

Always on

Run it for a team

On a fresh Debian or Ubuntu server with a domain pointed at it, one command sets up Docker, HTTPS and an owner account.

git clone https://github.com/real-kijmoshi/quanta.git && cd quanta sudo ./deploy/install.sh board.example.com you@example.com

Accounts, per-folder invitations, backups and password recovery are covered in the self-hosting guide.

Questions

Good to know

Do I need an account or internet?

No. Local mode has no accounts and works offline. Only cloud AI providers, the Cloudflare tunnel and on-demand Pyodide packages need a connection.

Where are my boards stored?

As plain JSON in ~/.quanta/data. Run quanta backup for a verified copy.

Is it safe to run other people's code?

Guests run Python in their own browser via Pyodide, and JavaScript in a browser worker. Host Python, AI and MCP are owner-only.

Does it work on an iPad?

Yes. Pressure, barrel-button erase and palm rejection work where the browser exposes them, and the optional Notes beta is built for PC and iPad.
